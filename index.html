Скільки коштує прибирання?

Оберіть тип прибирання, площу й додаткові послуги — ціна та тривалість перераховуються одразу. Фінальну суму менеджер підтвердить по телефону.

Як вбудувати на свій сайт

Калькулятор — це два файли без бібліотек. Ціни, послуги й знижки задаються в налаштуваннях, без зміни коду.

<link rel="stylesheet" href="calculator.css">
<div data-cleaning-calculator></div>
<script>
  window.CleaningCalculatorConfig = {
    minOrder: 1000,
    endpoint: '/api/lead'   // куди надсилати заявку
  };
</script>
<script src="calculator.js"></script>

Для WordPress є плагін: шорткод [cleaning_calculator], заявки зберігаються в адмінці. Код: github.com/MaKsImKa22/cleaning-calculator.

Демо-проєкт для портфоліо. Ціни умовні, заявка в демо-режимі нікуди не надсилається.
